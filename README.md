# Agrani Technologies & Services Limited

Marketing website for Agrani Technologies & Services Limited, built with Next.js and the App Router.

## Development

```bash
npm install
npm run dev
```

The application is available at [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run build
npm run lint
```

The main route structure lives in `app/`, reusable site chrome in `components/`, and design assets in `public/assets/`.
